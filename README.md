# Newslang Word Generator

A simple Python tool and web application to generate new, playful, and sometimes quirky words based on user-provided keywords.

## Overview

Newslang helps you invent words by taking your keywords, finding related concepts using NLTK's WordNet, and then applying a variety of linguistic transformations to create novel terms. It offers both a command-line interface (CLI) for quick generation and a user-friendly web application for a more interactive experience. It's designed to be a fun aid for creative writing, brainstorming, or just playing with language.

## Features

This tool employs several techniques to generate new word candidates:

*   **Keyword Analysis:** Uses NLTK's WordNet to find words semantically related (synonyms, hypernyms) to your input keywords, expanding the base for generation.
*   **Blending/Portmanteaus:** Creatively combines parts of two words (either related words or a keyword and an inspirational quirky word).
*   **Affixation (Common & Playful):** Adds common English prefixes (e.g., `re-`, `un-`) and suffixes (e.g., `-ing`, `-able`), as well as a selection of more playful and trendy affixes (e.g., `mega-`, `-tastic`, `-inator`, `-izzle`, `-core`, `giga-`) to create new forms.
*   **Clipping:** Shortens words, mimicking common slang formation (e.g., `information` -> `info`).
*   **Phonetic Modification:** (Currently a simple vowel/consonant substitution, scope for enhancement) Introduces slight phonetic variations.
*   **Reduplication:** Creates words by repeating a segment, often the end of the word (e.g., `happy` -> `happyappy`).
*   **Phonetic Respelling:** Applies common phonetic respellings to words (e.g., `running` -> `runnin\'`, `cool` -> `kewl`, `you` -> `u`).
*   **Wildcard Generation:** For each request, one "wildcard" word is specially generated by combining one of your keywords with an inspirational word from a curated list of quirky English words (e.g., `QUIRKY_WORDS` = `["kerfuffle", "flummox", ...]`). This aims to add an element of surprise and greater novelty.
*   **Web Interface:** Provides an interactive way to input keywords and desired word count (via a slider), and view generated results.

## Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/sim-lu/newslang.git
    cd newslang
    ```
2.  **Create and activate a virtual environment:**
    ```bash
    python3 -m venv venv
    source venv/bin/activate 
    # On Windows use `venv\Scripts\activate`
    ```
3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt 
    # This installs NLTK, PyTest, and Flask.
    ```
4.  **Download NLTK data:** The script and web app will attempt to download the necessary WordNet data on first run. If you encounter SSL issues on macOS, you may need to run the `Install Certificates.command` script typically located in your Python application folder (`/Applications/Python X.Y/`).

## Usage

You can use Newslang either via its command-line interface or the web application.

### Web Application

1.  **Start the Flask development server:**
    ```bash
    python app.py
    ```
2.  **Open your web browser** and navigate to: `http://127.0.0.1:5000`

    You can then enter your keywords, select the number of words to generate using the slider, and click "Generate!"

    *(Note: A screenshot of the web interface would go here.)*

### Command-Line Interface (CLI)

Run the `word_generator.py` script from the command line, providing one or more keywords:

```bash
python word_generator.py keyword1 [keyword2 ...] [-n NUMBER]
```

*   `keyword1 [keyword2 ...]` : One or more base keywords.
*   `-n NUMBER` or `--num NUMBER`: (Optional) The desired number of words to generate (default is set in the script, currently 10, with one being a wildcard).

The output will list the regular generated words, followed by the "Wildcard:" word if one was successfully created.

**CLI Examples:**

```bash
# Generate words based on "playful", "fun", "game"
python word_generator.py playful fun game

# Generate a different number of words based on "technology", "network", "speed"
python word_generator.py technology network speed -n 5 
# (This will result in 4 regular words + 1 wildcard)
```
